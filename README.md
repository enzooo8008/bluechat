# Blue Chat 💙

A simple two-person real-time chat website.

## Run locally
1. Install Node.js 18+.
2. Open a terminal in this folder.
3. Run `npm install`
4. Run `npm start`
5. Open http://localhost:3000

## Put it online
Deploy the folder to a Node.js-compatible host such as Render, Railway, or another service that supports a long-running Node server. Use the start command `npm start`.

## Important
This version stores the last 500 messages in `data/messages.json`. It is a simple starter app, not a production-secure private messenger. For a truly private app, add authentication and a proper database before sharing sensitive information.
